# Nexus HRMS

Nexus HRMS is a Spring Boot-based Human Resource Management System designed to manage employees, departments, projects, attendance, leaves, and performance-related operations using RESTful APIs.

---

## 🚀 Features

- Employee Management
- Department Management
- Project Management
- Assignment Management
- Attendance Management
- Leave Management
- Leave Balance Management
- Employee Promotion
- Employee Transfer
- Performance Review
- Employee Profile Management
- Document Management
- Project Milestone Tracking

---

## 🛠 Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Postman
